Рисование продолжает область: новые штрихи объединяются с уже нарисованным, старые не исчезают. Ластик чистит только выбранный слой. Рисуется только по суше — морская часть обрезается по береговой линии.

Маски
Можна вибрати кілька масок: шар обрізається об'єднанням їхніх контурів. Працює і для зон, і для стрілок.
Наложение
Режим накладання заливки на карту: множення затемнює, екран підсвічує, різниця інвертує. Контур і підпис залишаються звичайними.

Напрямок градієнта
Заливка плавно переходить від основного кольору до другого. Працює для зон і стрілок; контур і підпис не змінюються.
Границы
Твёрдые границы не дают другим слоям рисовать поверх этого слоя. У мягкого слоя новая рисовка соседнего слоя стирает его в месте перекрытия.
Малювання
«Суша й вода» дозволяє заливати море й озера — берегова лінія більше не обрізає шар.

ШАРИ КАРТИ
Пунктирні межі областей малюються окремим шаром поверх підкладки й не потрапляють у дані карти.
Эффекты карты сохраняются и повторяются в просмотре. Контур прошлого дня рисуется пунктиром и только для просмотра — в данные не попадает.
