# LINESTATE

Оперативная карта на MapLibre GL JS. Редактор — `admin/`, просмотр — корень репозитория.

## Первая публикация

Репозиторий уже инициализирован (ветка `main`). Осталось добавить remote и запушить:

```bash
git remote add origin https://github.com/<user>/<repo>.git
git add .
git commit -m "linestate: map viewer and editor"
git push -u origin main
```

Затем **Settings → Pages → Source → GitHub Actions**. Дальше сайт пересобирается
автоматически при каждом пуше в `main`.

## Как опубликовать карту (GitHub Pages)

1. Откройте `admin/` → вкладка **ФАЙЛ** → **«Экспорт для сайта (data/map.json)»**.
2. Полученный `map.json` положите в папку `data/` вместо текущего файла.
3. Закоммитьте и запушьте в ветку `main`:

   ```bash
   git add data/map.json
   git commit -m "map: update data"
   git push
   ```

4. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
   Workflow `.github/workflows/pages.yml` сам соберёт и выложит сайт при каждом пуше.

После публикации просмотр берёт дату из `data/map.json`, если в браузере посетителя
нет локально сохранённых данных. Локальные данные редактора всегда имеют приоритет,
поэтому изменение `map.json` сразу видно на сайте, но не ломает вашу рабочую копию.

### Что важно знать про данные

- Редактор хранит даты в `localStorage` браузера.
- `data/map.json` — снимок всех дат для публикации, включая позиции подписей слоёв.
- Если файл не загрузился (первый запуск без публикации), карта просто остаётся пустой.

## Возможности просмотра

- **Панель слоёв** открывается кнопкой «Шари» справа сверху, старую постоянную панель убрали.
- **Подписи** — кнопка «Підписи» в панели. Подписи слоёв можно перетаскивать прямо по карте;
  кнопка `◎` в строке слоя возвращает подпись в центр. Позиция сохраняется в данные даты
  и попадает в экспорт.
- **Просування** — кнопка в нижней панели. Считает разницу с соседней датой и оставляет
  светлую подсветку: зелёным — прирост, бледно-красным — отход. Анимация продвижения удалена.
- Зум и панорама — нативные жесты MapLibre, страна/области — отдельный слой подписей.

## Локальный запуск

Любой статический сервер из корня проекта, например:

```bash
npx serve .
```

`admin/index.html` — редактор, `index.html` — просмотр.
